# 연구원 공개 일정 조회 (ji-calendar)

공개 4대 캘린더(과제·업무·근태·기타)와 공식행사를 **읽기 전용**으로 본다. MCP 서버 `ji-calendar` 의 도구를 부른다.
개인 기본 캘린더·유연근무 시간은 보지 않는다. 일정 만들기·고치기는 없다.

## 순서
1. **이름 → `search_people`**: 사람 이름(일부·이메일 아이디·부서 이름도 됨)으로 먼저 찾는다.
   - 여러 명이 나오면(동명이인) 고르지 말고 후보(부서·이메일)를 보여 주고 누구인지 묻는다.
   - 못 찾으면 그렇다고 말하고 다른 표기(성+이름, 부서)를 묻는다.
2. **날짜 정하기**: "다음 주"·"내일" 같은 말은 오늘 날짜로 `YYYY-MM-DD` 범위로 바꾼다(끝 날짜 포함, 최대 31일).
3. **`get_schedule(start, end, people=[이메일 또는 정확한 이름])`**: 1에서 확인한 사람으로 부른다. 부서 전체면 `group`.
   공통 빈 시간은 `find_common_free_time`(최대 14일).
4. 결과를 날짜순으로 짧게 정리한다. 응답의 `caveats`·`coverage`(누락 캘린더·동기화 시각)를 한 줄로 덧붙인다.

## 꼭 지킬 것
- **일정이 없다고 "참석 가능"·"비어 있음 확정"이라고 말하지 않는다.** "공개 캘린더에 등록된 일정이 없다"고만 말하고, 개인 일정은 본인에게 확인하라고 한다.
- 이 조회는 **그룹웨어(gw)·Google 계정과 상관없다.** `gw` 점검 실패, `gcalcli`·Google 로그인이 없다는 이유로 멈추거나 "조회할 수 없다"고 하지 않는다. 이 도구만 쓴다.
- `ji-calendar` 도구가 안 보이거나 접속이 안 되면 그 사실만 알리고 `jaix doctor` 의 '원격 MCP ji-calendar' 줄을 보라고 안내한다(등록 안 됨 → `jaix update`, 접속 실패 → 인터넷 확인 후 AI센터).
- 조회한 일정을 묻지 않은 사람에게 퍼뜨리지 않는다(슬랙 채널에 통째로 붙이지 않기).
