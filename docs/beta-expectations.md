# 베타 기대 범위와 시험 프롬프트 (jaix v2026.11.05.20 기준)

베타테스터(AI센터 + 인공지능연구회 소모임)가 **지금 판을 설치하고 JX 코드까지 넣었을 때 어디까지 되어야 하는지**와,
그것을 **어떻게 시험하는지**를 한 장에 모은다. 시험은 가능한 한 코드(`jaix selftest`·CI)로 하고, 사람은 화면에서만 볼 수 있는 것만 확인한다. 베타 기간에는 상세판(5절), 11/10 이후 전사에는 간소판(6절)을 쓴다.
전체 인수 시험(11/10 배포 판정용)은 [acceptance-tests.md](acceptance-tests.md), 설치 절차는 [install-guide.md](install-guide.md).

- 기준 판: jaix **v2026.11.05.20** (2026-11-05 21:03 KST 릴리스)
- 표의 ✅ 는 **실측으로 확인된 것**, ◯ 는 설계상 되어야 하지만 베타에서 처음 확인하는 것이다. 근거는 표 아래 "확인 이력".
- 이 문서는 판이 바뀌면 같이 고친다(기준 판 줄부터).

공통 전제:
- **Code 탭에서 `/hwp` 로 jaix 도구가 보여야** 나머지 시험이 의미 있다. 안 보이면 `jaix doctor` 의 `[실패]` 줄(대개 Git)부터 해결한다.
- **Cowork는 개인 구독 계정이면 마켓을 직접 추가**해야 한다(install-guide 4-2절). Team 좌석은 관리자 배포로 온다.
- **Hermes 봇은 PC가 켜져 있고 로그인돼 있을 때만** 답한다. 쓸 AI는 ChatGPT 유료(Plus 이상) 또는 회사 Claude 계정(Team). 개인 Claude Pro로는 안 된다.

### 알려진 한계 (지금 판)
1. **Cowork는 claude.ai 쪽에서 플러그인을 돌린다.** 스킬 문서는 읽지만 이 PC의 CLI(hwp-agent·hwp2pdf·gw·jaix)를 실행하지 못한다. HWP 편집·경제파급효과는 "로컬 MCP" 경고 뒤 실제로 PC에서 도는지 베타에서 확인한다. 실제 파일 작업은 **Code 탭**으로 안내한다.
2. **메일은 Cowork에서 건너뜀**(최상위 `bin/` 이 있는 플러그인은 claude.ai 가 받지 않음). mail-skill v2026.11.05.2 가 `cli/` 로 옮겼고, 잠금에 올리면 풀린다. 올린 뒤 이 줄을 고친다.
3. **설치 파일 Defender 격리**: 서명이 없어 판에 따라 설치 **뒤** 받은 exe 가 격리될 수 있다(설치된 jaix 는 영향 없음). 코드 서명은 11/9 센터회의 안건.
4. **doctor 는 Cowork 에 추가한 마켓을 보지 못한다.** Cowork 쪽 상태는 Plugins 화면으로 확인한다.

## 3. 사용자가 직접 하는 첫 설정

코드로 대신할 수 없다(본인 비밀번호·본인 승인이 필요함). `jaix selftest` 는 이것들을 `[설정 필요]` 로 따로 알려 준다.

| 무엇 | 언제 필요 | 하는 법 | selftest 가 보나 |
|---|---|---|---|
| Claude 앱 로그인 | 설치 전 | 앱에서 로그인 | — |
| Cowork 마켓 추가 + GitHub 앱 접근 허용 | 개인 구독 계정이 Cowork 쓸 때 | install-guide 4-2절 | ❌ (PC 밖) |
| 커넥터 연결(Google Calendar·Drive·Gmail·Slack·monday) | 업무일지·일정·드라이브 | Customize → Connectors → Connect | ❌ (PC 밖) |
| 그룹웨어 로그인 | gw 처음 쓸 때(원내망) | 명령창 `gw login` → 뜨는 창에 아이디·비밀번호 | ◯ 저장 여부만 |
| 회사메일 앱 비밀번호 | 메일 처음 쓸 때 | 웍스에서 앱 비밀번호 발급 → PowerShell `mailskill setup` | ◯ |
| 웍스 로그인 | 웍스 드라이브 쓸 때 | `jaix works login` | ◯ |
| Hermes 가 쓸 AI 로그인 | Hermes 고른 경우 | 설치 끝 [로그인 창 열기] 또는 시작 메뉴 **JAIX Hermes 로그인** | ◯ |
| 한컴 첫 실행 동의 | HWP→PDF 처음(한컴 2022 외 판) | 한글을 한 번 직접 열어 동의 창에 답함 | ◯ |

## 4. 시험을 어디서 무엇으로 하나

사람이 하는 시험은 **코드로 못 보는 것만** 남긴다.

| 층 | 누가·언제 | 무엇을 보나 |
|---|---|---|
| A. CI | 모든 PR·릴리스, Windows 러너 | 잠금 플러그인 설치, `jaix setup`·`doctor`, `jaix selftest`(HWP 변환·추출, MCP 서버 기동) |
| B. `jaix selftest` | **사용자 본인 PC, 한 줄** | 위 + 그 PC 에서만 보이는 것: 한컴 PDF 변환, 원내망 그룹웨어 접속, Hermes 게이트웨이, 첫 설정 여부 |
| C. `jaix selftest --agent` | AI센터, 깨끗한 계정(`jaix-fresh`) | Claude 가 실제로 jaix 도구를 골라 쓰는지(사용량이 들어서 기본은 끔) |
| D. 사람 확인 | 아래 상세판(베타)·간소판(11/10 이후) | 화면 조작: 업데이트 창, `/` 목록, Cowork, 슬랙 봇 |

시험 환경:

| 기호 | 환경 | 무엇을 보나 |
|---|---|---|
| E1 | 깨끗한 Windows 계정, 원내망 | 처음 설치 |
| E2 | 이미 쓰던 PC(어제 설치), 원내망 | 업데이트 창 / `jaix update`, 기존 설정 유지 |
| E3 | 원외(집·와이파이) | gw 만 빠지고 나머지는 되는지 |
| E4 | 개인 Pro / 회사 Team | Cowork 마켓 직접 추가 vs 관리자 배포, Hermes 쓸 AI 가부 |
| E5 | + JX 코드 + ChatGPT 유료 또는 회사 Team | Hermes 봇 |

## 5. 상세판 — 베타 기간(소모임·AI센터, ~11/9)

순서대로 하고, 결과를 소모임 채널에 올린다. 시험 파일은 **개인정보 없는** `.hwp` 하나를 `바탕 화면\시험 자료\` 에 둔다.

| # | 할 일 | 통과 기준 |
|---|---|---|
| D1 | (어제 설치한 분) 로그온 때 "JAIX 새 판이 있습니다" → [예]. 안 뜨면 PowerShell `jaix update` | v2026.11.05.20 이 됨, 지난 선택 유지 |
| D2 | PowerShell `jaix selftest` → **결과 전체를 채널에 붙여 넣기** | `[실패]` 0. `[설정 필요]` 는 3절 표대로 하고 다시 실행 |
| D3 | Code 탭 입력창 `/hwp` | hwp-agent·hwp2pdf 가 목록에 나옴 |
| D4 | Code 탭: `바탕 화면\시험 자료\공문.hwp 를 hwpx 로 바꿔줘` | 같은 폴더에 `.hwpx` 생기고 한글에서 열림 |
| D5 | Code 탭: `다음 문단을 보고서 톤으로 고쳐줘: <다체 문단 2-3개>` | 음슴체·마침표 없음·문장형 bullet |
| D6 | (원내망) Code 탭: `내 결재 대기 문서 보여줘` | 처음이면 로그인 창 → 본인 결재함 목록 |
| D7 | Code 탭: `이번 주에 나한테 온 메일 5개 보여줘` | 처음이면 `mailskill setup` 안내 → 설정 뒤 목록. 발송하지 않음 |
| D8 | Cowork 입력창 `/h` (마켓 추가 뒤) | jaix 스킬이 보임(메일은 아직 없음) |
| D9 | Cowork: `.hwpx` 파일을 첨부하고 `이 문서 요약해줘` | 요약됨. **어떻게 읽었는지**(도구 실행/그냥 압축 해제) 메모 — 2절 ❓ 확인용 |
| D10 | Cowork: `내일 일정과 빈 시간 알려줘` (Calendar 연결 뒤) | 맞음 |
| D11 | (Hermes) 봇 DM `안녕` | 1분 안에 답 |
| D12 | (Hermes) 봇 DM: D4 와 같은 변환 요청 | PC 에 `.hwpx` 생김(승인을 물으면 승인) |
| D13 | (Hermes) PC 를 잠근 채 봇 DM `안녕` | 답이 오는지 메모 |

```

D4 ✅  D9 ❌ 파일을 못 읽음(사진)  D11 ✅  D13 ⚠️ 잠그면 답 없음
```

## 6. 간소판 — 11/10 이후 전사

베타에서 상세판이 안정되면 이것만 남긴다.

1. 설치가 끝나면 PowerShell 에서 `jaix selftest` → `[실패]` 가 있으면 결과를 AI센터 채널에 올린다. `[설정 필요]` 는 안내대로 한다.
2. Claude 앱 Code 탭에서 `/hwp` 를 쳐서 jaix 도구가 보이는지 확인한다.
3. (슬랙 Hermes 를 쓰는 분) 봇에게 `안녕` 을 보내 답이 오는지 확인한다.
