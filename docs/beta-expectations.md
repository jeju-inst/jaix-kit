# 베타 기대 범위와 시험 프롬프트 (jaix v2026.11.05.20 기준)

그것을 **어떤 환경에서 어떤 말로 시험하는지**를 한 장에 모은다.
전체 인수 시험(11/10 배포 판정용)은 [acceptance-tests.md](acceptance-tests.md), 설치 절차는 [install-guide.md](install-guide.md).

- 표의 ✅ 는 **실측으로 확인된 것**, ◯ 는 설계상 되어야 하지만 베타에서 처음 확인하는 것이다. 근거는 표 아래 "확인 이력".

공통 전제:
- **Code 탭에서 `/hwp` 로 jaix 도구가 보여야** 나머지 시험이 의미 있다. 안 보이면 `jaix doctor` 의 `[실패]` 줄(대개 Git)부터 해결한다.
- **Cowork는 개인 구독 계정이면 마켓을 직접 추가**해야 한다(install-guide 4-2절). Team 좌석은 관리자 배포로 온다.
- **Hermes 봇은 PC가 켜져 있고 로그인돼 있을 때만** 답한다. 쓸 AI는 ChatGPT 유료(Plus 이상) 또는 회사 Claude 계정(Team). 개인 Claude Pro로는 안 된다.

### 알려진 한계 (지금 판)
1. **Cowork는 claude.ai 쪽에서 플러그인을 돌린다.** 스킬 문서는 읽지만 이 PC의 CLI(hwp-agent·hwp2pdf·gw·jaix)를 실행하지 못한다. HWP 편집·경제파급효과는 "로컬 MCP" 경고 뒤 실제로 PC에서 도는지 베타에서 확인한다. 실제 파일 작업은 **Code 탭**으로 안내한다.
2. **메일은 Cowork에서 건너뜀**(최상위 `bin/` 이 있는 플러그인은 claude.ai 가 받지 않음). mail-skill v2026.11.05.2 가 `cli/` 로 옮겼고, 잠금에 올리면 풀린다. 올린 뒤 이 줄을 고친다.
3. **설치 파일 Defender 격리**: 서명이 없어 판에 따라 설치 **뒤** 받은 exe 가 격리될 수 있다(설치된 jaix 는 영향 없음). 코드 서명은 11/9 센터회의 안건.
4. **doctor 는 Cowork 에 추가한 마켓을 보지 못한다.** Cowork 쪽 상태는 Plugins 화면으로 확인한다.

| E5 | E1 또는 E2 + **JX 코드** + ChatGPT 유료 또는 회사 Team | Hermes 봇 연결·응답·도구 호출 |
