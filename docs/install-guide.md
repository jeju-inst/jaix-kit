# JAIX 도구 설치 안내 (연구원용)

연구원 PC(Windows)에 JAIX 도구(HWP 편집 · 업무일지 · 보고서 작성 표준)를 까는 방법이다.
관리자 권한과 재부팅은 필요 없고, 보통 몇 분이면 끝난다.

> 그림 자리: 아래 `(그림 n)` 은 jaix-win 실기 때 찍은 화면으로 채운다. 파일은 `docs/images/install/` 에 둔다.

## 0. 먼저 있어야 하는 것
- **Claude 데스크톱 앱**(또는 Codex). 로그인까지 해 둔다.
  - 표준 사용자 계정에서 Claude 데스크톱 앱을 처음 설치할 때는 Windows가 관리자 자격 증명을 물을 수 있다. 이것은 JAIX가 아니라 앱 설치 단계다. 막히면 AI센터에 연락한다.
- 원내망 접속(그룹웨어 도구 `gw` 를 받을 때만 필요하다. 원내망이 아니면 gw만 건너뛰고 나머지는 깔린다).

## 1. 설치 파일 받기
https://github.com/jeju-inst/jaix-kit/releases/latest/download/jaix-setup.exe

## 2. "Windows의 PC 보호" 창이 뜨면 — 추가 정보 → 실행
설치 파일에 코드 서명을 하지 않아서 처음 실행할 때 SmartScreen이 막을 수 있다. 위험하다는 뜻이 아니라 "아직 평판 기록이 없는 파일"이라는 뜻이다.

1. 파란 창에서 **추가 정보**를 누른다.
   (그림 1 — `smartscreen-1.png`: "Windows의 PC 보호" 창, **추가 정보** 링크 표시)
2. 아래에 생긴 **실행** 버튼을 누른다. 게시자는 "알 수 없는 게시자"로 나온다.
   (그림 2 — `smartscreen-2.png`: 앱 이름 `jaix-setup.exe` · **실행** 버튼 표시)

**Windows 보안(Defender) 알림이 뜨면** 지우거나 허용하지 말고 그 화면 그대로 AI센터에 연락한다.

## 3. 설치 화면
1. **어디에서 쓰시나요?** — 쓰는 AI를 고른다. Claude는 기본으로 체크돼 있고, Codex는 PC에 있으면 체크돼 있다. "슬랙으로도 쓰기(Hermes)"를 고르면 다음 두 화면이 더 나온다.
   - **슬랙 연결 코드**: AI센터에서 받은 `JX-…` 코드를 붙여 넣는다. 한 번만 쓸 수 있고 72시간 뒤 만료된다. **원내망에서 설치해야 한다.** 코드가 없으면 비워 두면 된다. 그러면 Hermes만 깔리고, 나중에 코드를 받아 다시 설치하면 슬랙이 연결된다.
   - **Hermes가 쓸 AI**: 이미 쓰는 구독(ChatGPT 또는 Claude)을 고른다.
   - Hermes 설치는 처음에 10-20분 걸리고 약 3GB를 쓴다.
   (그림 3 — `setup-channels.png`)
2. **도구 설치 중** — 런타임을 받고 AI에 도구를 등록한다. 몇 분 걸릴 수 있다. 기존 설정은 지우지 않고, 바꾸기 전에 백업한다.
3. **설치 완료 · 이렇게 쓰세요** — 고른 AI별 안내가 나온다. 읽은 뒤 **[다음]**을 한 번 더 눌러야 마지막 화면(**[마침]**)이 나온다.
   (그림 4 — `setup-guide.png`)

이 안내는 시작 메뉴의 **JAIX 점검**으로 언제든 다시 볼 수 있다.

## 4. 설치 뒤 꼭 할 것 — 앱 다시 시작
- **Hermes(슬랙)**: 마지막 화면의 **Hermes AI 로그인 창 열기**를 켜 둔 채 [마침]을 누른다. 창에 나온 안내대로 브라우저에서 로그인·승인한다(ChatGPT는 코드 입력). 그다음 슬랙에서 봇 `Hermes-<아이디>`에게 DM "안녕"을 보내 본다. **PC가 켜져 있어야 봇이 답한다.**
  - 슬래시 명령은 `/hermes-<아이디>` 뒤에 붙인다. 예: 새 대화는 `/hermes-<아이디> new`, 도움말은 `/hermes-<아이디> help`. 도움말 목록에 `/new`처럼 보여도 그대로 치면 다른 앱의 명령이 된다.
- **Claude**: 앱을 **완전히** 종료했다가 다시 연다. 창의 X로 닫는 것만으로는 꺼지지 않는다 — 화면 오른쪽 아래 알림 영역(^)의 Claude 아이콘을 오른쪽 클릭 → **Exit**.
  - Code 탭에서 도구를 쓸 수 있다. Cowork(채팅)에서 쓰는 도구는 기관 관리자 배포로 내려온다.
- **Codex**: Codex를 다시 시작한다.
- **명령창**(cmd · PowerShell)은 새로 연다. 이미 열려 있던 창에서는 새로 깐 `jaix` · `gw` 를 찾지 못한다.

## 5. 새 버전
- Claude는 앱을 다시 열 때 새 버전을 저절로 받는다.
- Codex 쪽은 로그온할 때 jaix가 저절로 맞춘다(작업 스케줄러 `jaix-update`, 이 사용자 범위).
- 직접 맞추려면 시작 메뉴의 **JAIX 업데이트**를 누른다.

## 6. 문제가 있으면
시작 메뉴의 **JAIX 점검**(`jaix doctor`)을 눌러 나온 결과를 AI센터에 보낸다.

### HWP 미리보기가 "근사 렌더(rhwp)"로만 나올 때
한글을 닫은 상태인데도 그렇다면, 이 PC 계정에서 한글을 **한 번 직접 열어** 첫 실행 "사용성 데이터 수집 동의" 창에 답한 뒤 닫는다. 보이지 않게 띄운 한글이 그 창에서 멈췄기 때문이다. jaix 설치가 "동의 안 함"을 미리 기록하지만, 한글을 이미 연 적 있는 계정은 건드리지 않는다.

### jaix보다 먼저 Hermes를 따로 설치한 경우(AI센터 등)
Hermes 설정(config.yaml)의 hwp-agent 항목 args 맨 앞에 `--python`, `3.12`를 넣은 뒤 PC를 다시 시작하세요(또는 Hermes gateway 재시작).

## 7. 지우기
Windows **설정 → 앱 → 설치된 앱**에서 "JAIX 원내 AI 도구"를 제거한다. 로그온 자동 갱신 작업도 함께 지워진다. Claude·Codex 설정에 등록한 도구 항목은 그대로 남는다.
