# JAIX 도구 설치 안내 (연구원용)

연구원 PC(Windows)에 JAIX 도구(HWP 편집 · 업무일지 · 보고서 작성 표준)를 까는 방법이다.
관리자 권한과 재부팅은 필요 없고, 보통 몇 분이면 끝난다.

> 그림 자리: 아래 `(그림 n)` 은 jaix-win 실기 때 찍은 화면으로 채운다. 파일은 `docs/images/install/` 에 둔다.

## 0. 먼저 있어야 하는 것
- **Claude 데스크톱 앱**(또는 Codex). 로그인까지 해 둔다.
  - 표준 사용자 계정에서 Claude 데스크톱 앱을 처음 설치할 때는 Windows가 관리자 자격 증명을 물을 수 있다. 이것은 JAIX가 아니라 앱 설치 단계다. 막히면 AI센터에 연락한다.
- 원내망 접속(그룹웨어 도구 `gw` 를 받을 때만 필요하다. 원내망이 아니면 gw만 건너뛰고 나머지는 깔린다).

## 1. 설치 파일 받기
https://github.com/jeju-inst/jaix-kit/releases/latest/download/jaix-setup.exe

## 2. "Windows의 PC 보호" 창이 뜨면 — 추가 정보 → 실행
설치 파일에 코드 서명을 하지 않아서 처음 실행할 때 SmartScreen이 막을 수 있다. 위험하다는 뜻이 아니라 "아직 평판 기록이 없는 파일"이라는 뜻이다.

PC에 따라 이 창이 뜨지 않을 수 있습니다. 뜨면 [추가 정보] → [실행]을 누르세요.

1. 파란 창에서 **추가 정보**를 누른다.
2. 아래에 생긴 **실행** 버튼을 누른다. 게시자는 "알 수 없는 게시자"로 나온다.

**회사 보안 프로그램(에스원VP) "주의 — 앱 격리 검사" 창이 뜨면** 파일 처리 방법에서 **파일 해시 예외 처리 후 실행**(또는 **한 번만 실행**)을 고르고 확인한다. 처음 보는 파일이라 묻는 것이고, 파일을 다시 받아도 같은 창이 또 뜬다(2026-11-06 연구원 PC 보고). 고른 뒤에도 설치가 이어지지 않으면 그 화면을 AI센터에 보낸다.

**Windows 보안(Defender) 알림이 뜨면** 지우거나 허용하지 말고 그 화면 그대로 AI센터에 연락한다.

## 3. 설치 화면
1. **어디에서 쓰시나요?** — 쓰는 AI를 고른다. Claude는 기본으로 체크돼 있고, Codex는 PC에 있으면 체크돼 있다. "슬랙으로도 쓰기(Hermes)"를 고르면 다음 두 화면이 더 나온다.
   - **슬랙 연결 코드**: AI센터에서 받은 `JX-…` 코드를 붙여 넣는다. 한 번만 쓸 수 있고 72시간 뒤 만료된다. **원내망에서 설치해야 한다.** 코드가 없으면 비워 두면 된다. 그러면 Hermes만 깔리고, 나중에 코드를 받아 다시 설치하면 슬랙이 연결된다.
   - **Hermes가 쓸 AI**: 미리 골라져 있지 않으니 하나를 고른다. **ChatGPT 유료 구독(Plus 이상)** 또는 **회사 Claude 계정(Team)**. 개인 Claude Pro 구독으로는 Hermes가 동작하지 않는다(Hermes 문서 providers.md "Subscription plans" 표에서 Pro ❌. 회사 Team 계정은 2026-11-05 studio에서 실측해 동작함).
   - Hermes 설치는 처음에 10-20분 걸리고 약 3GB를 쓴다.
   (그림 3 — `setup-channels.png`)
2. **도구 설치 중** — 런타임을 받고 AI에 도구를 등록한다. 몇 분 걸릴 수 있다. 기존 설정은 지우지 않고, 바꾸기 전에 백업한다.
3. **설치 완료 · 이렇게 쓰세요** — 고른 AI별 안내가 나온다. 읽은 뒤 **[다음]**을 한 번 더 눌러야 마지막 화면(**[마침]**)이 나온다.
   (그림 4 — `setup-guide.png`)

이 안내는 시작 메뉴의 **JAIX 점검**으로 언제든 다시 볼 수 있다.

## 4. 설치 뒤 꼭 할 것 — 앱 다시 시작
- **계정 연결(그룹웨어·회사메일·웍스)**: 시작 메뉴의 **JAIX 계정 연결**을 연다. 항목마다 됨/연결 필요가 보이고, [Y]를 누르면 그 항목의 입력 창이 뜬다. 비밀번호는 **뜨는 창에 본인이 직접** 넣는다(jaix·AI 는 값을 받지 않는다). 그룹웨어는 원내망(사무실·VPN)에서만 연결된다. 회사메일은 웍스 앱 비밀번호 발급 안내가 브라우저로 먼저 열린다. 비밀번호를 바꿨을 때도 여기서 다시 한다. Claude 에게 "메일 연결해 줘"라고 해도 같은 창이 뜬다(`jaix connect mail`).
- **Hermes(슬랙)**: 설치 안내 화면 다음의 **AI 구독 로그인** 화면에서 **[로그인 창 열기]**를 누른다. 열린 창의 안내대로 브라우저에서 로그인·승인한다(ChatGPT는 코드 입력). 끝나면 창이 닫히고 결과가 설치기 화면에 나온다. 건너뛰었거나 실패했으면 나중에 시작 메뉴의 **JAIX Hermes 로그인**(또는 새 명령창에서 `jaix hermes login`, 회사 Claude 계정이면 `--model claude`)으로 한다. 설치기는 로그인 창이 끝나기를 기다렸다가 넘어가므로, [마침] 뒤에 남는 창은 없다. 그다음 슬랙에서 봇 `Hermes-<아이디>`에게 DM "안녕"을 보내 본다. **PC가 켜져 있어야 봇이 답한다.**
  - 슬래시 명령은 `/hermes-<아이디>` 뒤에 붙인다. 예: 새 대화는 `/hermes-<아이디> new`, 도움말은 `/hermes-<아이디> help`. 도움말 목록에 `/new`처럼 보여도 그대로 치면 다른 앱의 명령이 된다.
  - 위험한 명령을 실행하기 전에 묻는 방식(승인 방식)은 슬랙에서 바꿀 수 없다. 바꾸려면 PC 명령창에서 `jaix hermes approvals manual`(위험 명령마다 묻기) 또는 `jaix hermes approvals smart`(기본, 위험해 보이는 것만 묻기)를 실행한다. 승인 끄기(off)는 AI센터만 할 수 있다.
  - 봇 이름(아이디)을 바꾸려면 AI센터에 요청한다. AI센터가 슬랙 앱 이름을 바꾸고 새 아이디를 알려 주면, PC 명령창에서 `jaix hermes rename <새 아이디>`를 실행한다. 슬래시 명령이 `/hermes-<새 아이디>`로 바뀌고 봇이 다시 시작된다. 그 전까지 새 명령은 "앱이 반응하지 않음"으로 실패하지만 DM은 계속 된다.
- **Claude**: 앱을 **완전히** 종료했다가 다시 연다. 창의 X로 닫는 것만으로는 꺼지지 않는다 — 화면 오른쪽 아래 알림 영역(^)의 Claude 아이콘을 오른쪽 클릭 → **Exit**.
  - Code 탭에서 도구를 쓸 수 있다. Cowork(채팅)에서 쓰는 도구는 기관 관리자 배포로 내려온다. 관리자 배포가 없는 개인 구독 계정이면 4-2절처럼 직접 추가한다(설치 완료 안내도 그 PC에서는 그렇게 알려 준다).
- **Codex**: Codex를 완전히 닫았다가 다시 연다.
- **왜 다시 여나**: jaix는 도구 위치를 사용자 환경변수로 알려 준다(예: `HWP2PDF_CLI` — 관리자가 따로 깐 낡은 hwp2pdf가 있어도 jaix 사본을 쓰게). 환경변수는 **새로 연 앱부터** 보이므로, 켜져 있던 Claude·Codex는 계속 예전 위치를 쓴다.
- **명령창**(cmd · PowerShell)은 새로 연다. 이미 열려 있던 창에서는 새로 깐 `jaix` · `gw` 를 찾지 못한다.
- **명령창에서 `claude` · `codex`**: 고른 채널(Claude·Codex)의 명령은 설치기가 챙긴다. 이미 있으면 그대로 두고, 깔려 있는데 명령창에서 안 잡히면(npm 전역 `%APPDATA%\npm`, `~\.local\bin` 이 PATH 에 없음) 사용자 PATH 에 올리고, 없으면 깐다(Claude Code는 공식 네이티브 설치와 같게 downloads.claude.ai 에서 받아 sha256 검증, Codex는 npm `@openai/codex`). 새 명령창을 열고 `claude`(또는 `codex`)를 한 번 입력해 로그인한다. `jaix doctor` 의 "claude 명령 · codex 명령" 줄이 새 창에서 잡히는지 보여 준다. Claude 데스크톱 앱 자체는 깔지 않는다(앱 설치는 관리자 권한이 필요할 수 있다 — https://claude.ai/download).

## 4-1. Claude 처음 쓸 때 — 모델 고르기 · 업무 계정 연결
설치와 상관없이 Claude 앱에서 한 번만 하면 된다.

- **모델은 Sonnet을 고른다.** 입력창 아래 모델 이름(예: `Opus 5.5`)을 눌러 **Sonnet**으로 바꾼다. 앱은 고른 모델을 기억한다.
  - Opus는 사용 한도를 몇 배 빨리 쓴다. 긴 보고서 초안·어려운 분석처럼 꼭 필요할 때만 그 대화에서 Opus로 바꾼다.
  - 명령창 Claude Code는 기관 설정으로 Sonnet이 기본이다(`/model` 로 그 세션만 바꿀 수 있다).
- **업무 계정 연결**: 왼쪽 **Customize → Connectors**에서 필요한 것만 **Connect**를 누르고, 계정은 아래처럼 고른다.

  | 커넥터 | 고를 계정 | 비고 |
  |---|---|---|
  | Google Calendar · Google Drive | `아이디@ji.re.kr` (Google) | 업무일지가 캘린더를 쓴다 |
  | Gmail | `아이디@jri.re.kr` (옛 도메인) | 받은 메일·지난 메일이 여기 있다. `ji.re.kr` 로 연결하면 비어 있다. 메일 **보내기**는 웍스에서 |
  | Slack | 제주연구원 워크스페이스 | |
  | monday.com | 본인 계정 | |

  - Google Docs·Sheets·Slides 커넥터는 연결하지 않아도 된다(Drive로 충분하다).
  - 연결은 각자 계정으로 하고, 한 번 하면 명령창 Claude Code에도 같이 보인다.

## 4-2. 개인 구독 계정으로 쓸 때 (11/10 전 베타)
기관 Team 계정 좌석이 아직 없고 **본인 Pro/Max 구독**으로 로그인했다면, 기관 관리자가 내려보내는 설정(기본 모델, Cowork 도구, 기관 커넥터)이 오지 않는다. 아래를 직접 한다. Team 좌석을 받으면 이 절은 할 필요 없다.

- **Code 탭·명령창 Claude Code**: 설치기(1-4절)가 도구를 넣어 주므로 그대로 쓴다. 개인 계정이어도 같다.
- **Cowork(채팅)에서 도구 쓰기**: 마켓을 직접 추가한다.
  1. 왼쪽 **Customize → Plugins** 탭으로 간다.
  2. **Add → Add marketplace**를 누르면 고르는 창이 뜬다. **Add from a repository**를 고르고 `jeju-inst/jaix-kit` 를 넣은 뒤 **Sync**를 누른다.
  3. GitHub 앱 접근을 물으면 허용한다.
  4. 목록에 나온 jaix 플러그인을 하나씩 **Add** 한다(업무일지 · HWP · 보고서 작성 · HWP→PDF 등. 목록은 계속 늘어난다). **메일 도구는 Cowork에서 쓸 수 없다** — Code 탭에서 쓴다.
  5. 입력창에 `/` 를 쳐서 jaix 스킬이 보이면 된다.
  - 새 버전이나 새 플러그인이 안 보이면 Plugins 탭에서 jaix 마켓을 새로고침(업데이트)한다.
- **모델**: 4-1절처럼 **Sonnet**을 직접 고른다. 명령창 Claude Code는 기관 기본값이 오지 않으므로 `/model sonnet` 으로 바꾼다.
- **업무 계정 연결**: 4-1절 표 그대로 **Customize → Connectors**에서 각자 연결한다(Slack · Google Calendar/Drive=`@ji.re.kr` · Gmail=`@jri.re.kr` · monday).
- **규정 Q&A**: 준비되면 AI센터가 주소를 알려 준다. **Customize → Connectors → + Add → Add custom connector**에 그 주소를 넣고 웍스 계정으로 로그인한다. 아직은 없다.

> 근거: Anthropic 도움말 "Use plugins in Claude"(Pro·Max 포함 모든 유료 요금제), "About custom connectors using remote MCP"(Pro·Max: Customize → Connectors), 2026-11-05 확인. 개인 계정에서 Cowork 마켓 추가가 실제로 되는지는 베타 때 확인한다.

## 5. 새 버전
- Claude는 앱을 다시 열 때 새 버전을 저절로 받는다.
- **설치·업데이트 뒤에는 Claude·Codex 앱을 완전히 닫았다 다시 연다**(4절 "왜 다시 여나"). 로그온 갱신 뒤라면 다음에 앱을 처음 열 때 이미 반영돼 있다.
- Codex·Hermes 쪽과 jaix 자체는 **저절로 갱신되지 않는다**. 가끔 시작 메뉴 **JAIX 업데이트**(= `jaix update`)를 실행한다. `jaix doctor` 의 "jaix 본체" 줄이 새 판이 있으면 알린다.
  - 왜 로그온 자동 갱신이 없나: 서명 없는 jaix 를 로그온 때 저절로 띄우는 항목(예약 작업이든 시작프로그램 바로가기든)이 있으면 Windows Defender 가 jaix 를 악성으로 오인해 격리했다(2026-11-04·11-07 실측). 예전 판이 둔 시작프로그램 `JAIX 갱신` 바로가기는 새 설치기·`jaix update` 가 지운다.
- **jaix 자체(설치본)의 새 판**: (아래는 로그온 갱신이 있던 때의 동작이다. 지금은 `jaix update` 를 실행할 때 같은 확인을 한다) 로그온 갱신이 6시간에 한 번 GitHub 최신 릴리스를 확인해, 새 판이면 설치기를 `%LOCALAPPDATA%\jaix\updates\` 에 받아 sha256 으로 검증해 둔다. 갱신이 끝나면 "JAIX 새 판이 있습니다 — 지금 업데이트할까요?" 창이 뜨고, **[예]를 누를 때만** 설치기가 이전 선택(Claude·Codex·Hermes, Hermes 모델) 그대로 진행 창만 띄워 설치한다. 그때 열려 있는 JAIX 창(Hermes 로그인 창·점검 중인 jaix 등)은 jaix 가 닫는다(열려 있으면 파일이 잠겨 설치가 멈춘다). 끝나면 결과 창이 뜨고 `updates\history.log` 에 한 줄 남는다. [아니요]면 다음 로그온 때 다시 묻는다. 지금 하려면 명령창에서 `jaix update --self`(묻지 않으려면 `--yes`). `jaix doctor` 의 "jaix 본체" 줄에도 새 판이 보인다. 급한 릴리스는 릴리스 본문에 `jaix-priority: critical` 줄을 넣으면 1시간 간격으로 확인한다.
- 직접 맞추려면 시작 메뉴의 **JAIX 업데이트**를 누른다.

## 6. 문제가 있으면
시작 메뉴의 **JAIX 점검**(`jaix doctor`)을 눌러 나온 결과를 AI센터에 보낸다.

### HWP 미리보기가 "근사 렌더(rhwp)"로만 나올 때
한글을 닫은 상태인데도 그렇다면, 이 PC 계정에서 한글을 **한 번 직접 열어** 첫 실행 "사용성 데이터 수집 동의" 창에 답한 뒤 닫는다. 보이지 않게 띄운 한글이 그 창에서 멈췄기 때문이다. jaix 설치가 "동의 안 함"을 미리 기록하지만, 한글을 이미 연 적 있는 계정은 건드리지 않는다.

### jaix보다 먼저 Hermes를 따로 설치한 경우(AI센터 등)
Hermes 설정(config.yaml)의 hwp-agent 항목 args 맨 앞에 `--python`, `3.12`를 넣은 뒤 PC를 다시 시작하세요(또는 Hermes gateway 재시작).

Windows **설정 → 앱 → 설치된 앱**에서 "JAIX 원내 AI 도구"를 제거한다. Claude·Codex 설정에 등록한 도구 항목은 그대로 남는다.
