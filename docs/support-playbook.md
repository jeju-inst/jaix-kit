# JAIX 사용자 지원 절차 (AI센터 담당자용)

연구원이 "모르겠다"고 할 때 AI센터가 어떤 순서로 도울지 정한다. 원칙은 **원격·자동으로 할 수 있는 건 AI센터가 하고, 방문은 정말 어쩔 수 없을 때만** 하는 것이다.
비밀번호는 **언제나 본인이 직접** 넣는다. 담당자가 대신 입력하거나 받아 적지 않는다(원격·방문 모두).

관련 문서: 설치 [install-guide.md](install-guide.md) · 기대 범위·첫 설정 [beta-expectations.md](beta-expectations.md)

## 1. 지원 단계

| 단계 | 누가 | 무엇 |
|---|---|---|
| 0 | 사용자 | 시작 메뉴 **JAIX 계정 연결**(`jaix connect`)에서 안 된 항목을 연결(2절). 설치기 마지막 안내문도 이것을 가리킴 |
| 1 | 사용자 + AI | 처음 쓸 때 AI가 `jaix connect <항목>` 으로 입력 창을 띄움(그룹웨어·메일·웍스·Hermes). 비밀번호는 그 창에 본인이 직접 |
| 2 | 사용자 | 시작 메뉴 **JAIX 자가시험**(`jaix selftest`) 결과를 채널에 붙여 넣음(`[설정 필요]` 는 0단계로) |
| 3 | AI센터(원격·관리자) | 3절 "관리자가 원격으로 끝내는 것" |
| 4 | AI센터(원격 화면 공유) | 사용자 화면을 보며 안내. 비밀번호는 사용자가 입력 |
| 5 | AI센터(방문) | 4절 방문 절차 |

## 2. 첫 설정을 어디서 하게 하나 (UI 방침)

지금은 도구를 처음 쓸 때 막혀서 안내를 받는 방식이다. 그룹웨어는 AI가 `gw login` 창을 띄워 주니 괜찮지만, **메일은 사용자가 PowerShell 을 직접 열어야 해서** 컴퓨터에 익숙하지 않은 사람에게 어렵다.

방침(구현됨 — `jaix connect`, `src/jaix/connect.py`):
- **시작 메뉴 "JAIX 계정 연결"**(`jaix connect`)이 항목별 상태(됨 / 연결 필요 / 지금은 못 함)를 보이고, 안 된 것을 하나씩 물어 연결한다. 비밀번호를 바꿨을 때, 나중에 하기로 했을 때도 여기서 다시 한다.
  - 그룹웨어(원내망일 때만): `gw login` 입력 창. 원외면 "원내망에서 다시"
  - 회사메일: 앱 비밀번호 발급 안내(mail-skill `docs/naver-works-app-password.md`)를 브라우저로 열고, 검은 창에서 `mailskill setup` 이 숨김 입력으로 받음. 결과: 0 완료 · 1 런타임 없음(→ `jaix setup`) · 2 터미널 아님 · 3 저장됐지만 로그인 실패(→ 새로 발급)
  - 웍스: `jaix works login` 브라우저 로그인
  - Hermes: `jaix hermes login`(설치 때 고른 구독)
- AI(Claude·Codex)가 `jaix connect <항목>` 을 부르면 메일·Hermes 는 **새 창**이 열리고 jaix 는 끝날 때까지 기다려 결과를 한 줄로 돌려준다. 값은 인자로 넘기지도 읽지도 않는다.
- `jaix selftest` 의 `[설정 필요]` 줄은 "시작 메뉴 'JAIX 계정 연결' (또는 jaix connect <항목>)" 로 안내한다.
- 설치기 UI 는 바꾸지 않았다. 마지막 안내문(설치 화면에 나오는 `jaix setup` 안내)에 "계정 연결" 절을 넣어 시작 메뉴를 가리킨다. 설치기 페이지 안에 [연결] 버튼을 두는 것은 Pascal 화면 변경 위험 대비 이득이 작아 미룸.
- 도구를 처음 쓸 때 막히는 경우(1단계)는 안전망으로 남긴다.

## 3. 관리자가 원격으로 끝내는 것 (사용자 조작 없음)

| 항목 | 방법 | 상태 |
|---|---|---|
| Hermes 슬랙 봇 만들기 | `provision_app.py` + `jaix hermes handoff` → JX 코드 DM | 운영 중 |
| Hermes 봇 이름 바꾸기 | 슬랙 앱 이름 변경 → 사용자 PC `jaix hermes rename`(원격 안내) | 운영 중 |
| 웍스 기관 앱 정보 | 원내망 `jaix setup` 이 자동으로 받음 | 운영 중 |
| 한컴 첫 실행 동의(2022) | jaix 가 미리 '동의 안 함'으로 답해 둠 | 운영 중 |
| Cowork 도구 배포 | Team 좌석: 관리자 콘솔 조직 플러그인 + managed settings | 11/10 Team 좌석부터. 개인 구독 계정은 사용자가 마켓 추가 |
| 커넥터 켜기 | 관리자 콘솔에서 조직 커넥터 켬. **OAuth 승인은 사용자 본인** | 11/10 |
| 도구 새 판·되돌리기 | 잠금 파일 변경 → 로그온 때 자동 반영 | 운영 중 |
| jaix 본체 새 판 | 릴리스 → 로그온 창 [예] (급하면 `jaix-priority: critical`) | 운영 중 |

사용자 비밀번호가 필요한 것(그룹웨어·메일 앱 비밀번호·웍스·Hermes AI 로그인·커넥터 OAuth)은 관리자가 대신할 수 없다.

## 4. 방문 절차

### 언제 방문하나
- 원격 화면 공유를 쓸 수 없거나, 원격으로 30분 넘게 해결되지 않을 때
- 설치기 자체가 실행되지 않음(보안 프로그램 차단·격리, 권한 정책)
- 사용자가 원격 연결을 어려워할 때

### 가져갈 것
- 최신 `jaix-setup.exe` 가 든 USB(받은 직후 바로 실행해야 Defender 격리를 피함 — 1절 install-guide)
- 이 문서와 [beta-expectations.md](beta-expectations.md) 3절 첫 설정 표
- 시험용 `.hwp` 파일 1개(개인정보 없는 것)

### 순서
1. **사용자에게 알리기**: "비밀번호는 직접 넣으셔야 합니다. 저는 화면을 보지 않겠습니다." 입력 때는 자리를 비키거나 고개를 돌린다.
2. **현재 상태**: 시작 메뉴 **JAIX 점검**(없으면 3번부터). 결과를 사진으로 찍어 둔다.
3. **설치·업데이트**: 원내망인지 확인 → `jaix-setup.exe` 실행 → 지난 선택이 체크돼 있는지 확인 → 끝까지.
   - "Windows의 PC 보호" → [추가 정보] → [실행]
   - 에스원VP "앱 격리 검사" 창 → [파일 해시 예외 처리 후 실행] 또는 [한 번만 실행] (다시 받아도 또 뜸)
   - Git 실패 화면이 나오면 사진을 찍고 계속한 뒤 채널에 올린다
4. **Claude 앱 완전히 껐다 켜기**: 알림 영역(^) Claude 아이콘 오른쪽 클릭 → Exit → 다시 열기.
5. **계정 연결**(사용자가 입력):
   - 시작 메뉴 **JAIX 계정 연결** → 연결 필요한 항목마다 [Y] → 뜨는 창에 본인이 입력(그룹웨어 아이디·비밀번호, 회사메일 앱 비밀번호, 웍스 브라우저 로그인, Hermes AI 구독). 메일은 붙여 넣은 뒤 메모장 등에 남은 것이 없는지 확인
   - Cowork(개인 구독 계정): install-guide 4-2절 마켓 추가
   - 커넥터: Customize → Connectors 에서 필요한 것 Connect
6. **확인**: PowerShell `jaix doctor` → `[실패]` 0 이 될 때까지. Code 탭에서 `/hwp` 확인, 시험 파일 hwpx 변환 1건, (원내망) `내 결재 대기 문서 보여줘` 1건. `jaix selftest` 가 나온 판부터는 그것으로 바꾼다(첫 설정 여부까지 `[설정 필요]` 로 보여 줌).
7. **기록**: 아래 양식으로 AI센터 채널(또는 소모임 채널)에 남긴다. 비밀번호·토큰·내부 주소는 적지 않는다.

```
방문 지원: 홍길동 · 2026-11-0x · 담당 ○○○
전: JAIX 점검 [실패] Git (사진)
한 일: jaix-setup v… 재설치, gw login, mailskill setup
후: jaix doctor 실패 0 · hwpx 변환 ✅ · 결재함 ✅
남은 것: (없음 / 원인 미상 → 이슈 #…)
```

## 5. 자주 막히는 곳

| 증상 | 원인 | 조치 |
|---|---|---|
| Code 탭에서 `/hwp` 가 안 나옴 | Git 설치 실패, 또는 앱을 완전히 안 껐음 | JAIX 점검 `[실패] Git` 확인 → 재설치 / 앱 Exit 후 다시 열기 |
| Cowork 목록에 jaix 가 없음 | 개인 계정 마켓 미추가, GitHub 앱 접근 미허용 | install-guide 4-2절 |
| 에스원VP "주의 — 앱 격리 검사" 창이 반복됨 | 처음 보는 파일 확인(새 판마다 해시가 바뀜). 다시 받아도 같음 | [파일 해시 예외 처리 후 실행] 또는 [한 번만 실행]. 전산에 예외 등록 요청 검토(#46) |
| 설치 파일이 사라짐·격리됨 | 서명 없는 새 파일 오탐 | 설치 뒤라면 무시. 설치 전이면 새로 받아 바로 실행 |
| Hermes 봇이 답이 없음 | PC 꺼짐·로그아웃, AI 로그인 안 함, 개인 Claude Pro | PC 켜기, JAIX Hermes 로그인, ChatGPT 유료 또는 회사 Team |
| 그룹웨어 "로그인이 필요합니다" | 비밀번호 변경·만료 | JAIX 계정 연결(또는 `jaix connect gw`) 다시 |
| 메일 인증 실패 | 앱 비밀번호 폐기·오타 | 새로 발급 → JAIX 계정 연결(또는 `jaix connect mail`) |
